Find sensitive files on your PC

Find Sensitive Files in the sidebar helps you find documents you may have forgotten about: scans and photos of Aadhaar and PAN cards, passports, voter ID cards, bank statements, cheques, salary slips, Form 16 and other tax forms. You check the list and encrypt the ones you want, in one go. It's free, with no limit on the number of files.

It runs only on your PC. Clavis searches only when you press Start search, never in the background. Nothing is uploaded, and Clavis doesn't keep a list of what it found: the list disappears when you press Close, when the vault locks or when you quit Clavis.

Search

  1. Open Find Sensitive Files in the sidebar, or press Find sensitive files… on the Encrypt & Decrypt page.
  2. Under Where to look, keep the folders you want: Documents, Downloads, Desktop, Pictures and, if WhatsApp Desktop is installed, the files received in WhatsApp. Add a folder… adds any other folder.
  3. Under What to read, leave Read text inside pictures and PDFs on to find scans and photos of documents (slower). Photos in Pictures are checked by name only, unless you tick Also read every photo in Pictures.
  4. Press Start search. Files appear as they're found, and you can switch to another page while it runs: the status bar shows the search, and Show brings you back. Stop keeps what was found so far.

What Clavis reads

  • File names, such as PAN_card.jpg or aadhar.pdf (also in Hindi and Tamil).
  • Text inside documents: Word (.docx), Excel (.xlsx), .txt and .csv files.
  • Text in pictures and PDFs (Windows only), using the text recognition built into Windows. Only the first page of a PDF is read. Password-protected PDFs aren't opened; they're checked by name.

Clavis skips system and program folders, AppData (except WhatsApp's folder), hidden folders such as .git, and files you've already encrypted. Files that OneDrive keeps online only are checked by name, so nothing is downloaded. On Linux, Clavis checks file names and documents only.

Check the list, then encrypt

Files are grouped as Likely sensitive (ticked) and Possibly sensitive (not ticked: check these yourself). Each file says why it's listed, for example Contains a PAN or File name says "bank statement". A 12-digit number only counts as an Aadhaar number when it passes Aadhaar's check digit and the word Aadhaar is nearby, so bank statements full of UPI reference numbers aren't mistaken for Aadhaar cards.

Untick anything that isn't sensitive and press Encrypt selected. Clavis encrypts them the usual way, with your vault password: the files end in .enc and the originals are overwritten, then deleted. Files received in WhatsApp will show as unavailable in WhatsApp on this PC afterwards; the copy on your phone isn't affected.

Never suggest a file

Use ⋯ next to a file (or right-click it) and choose Never suggest this file. Clavis keeps only a fingerprint of the file's location, not its name. Settings → Find Sensitive Files → Clear list brings them back.

Clavis can miss some documents, such as blurry photos, documents in Hindi or Tamil only, or files with unusual names. "No sensitive files found" means nothing matched in the folders you chose, not that there's nothing to protect.
